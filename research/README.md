# Research

Findings that inform the build plan. Each file answers one open question from
the "Research status" table in [PLAN.md](../PLAN.md).

These are inputs to decisions, not decisions themselves. When a finding settles
something, record the decision in PLAN.md and link back here.

| File | Question |
|------|----------|
| `R1-spec-conformance.md` | What exactly must summ implement to pass OCI conformance? |
| `R2-zero-copy-serving.md` | How should blob bytes reach the socket? |
| `R3-rocksdb-tuning.md` | How do we get prefix bloom filters given four prefix lengths? |
| `R4-zot-prior-art.md` | What has zot already solved that we would otherwise rediscover? |
| `R5-clients-and-ecosystem.md` | What does the real client do, and what already exists in Rust? |
